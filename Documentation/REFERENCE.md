# Référence du commutateur

Source examinée le 8 novembre 2026 : [Saiyed-Tanvir, pretty-moose-9](https://uiverse.io/Saiyed-Tanvir/pretty-moose-9).
Licence MIT vérifiée sur la page. Notice intégrale incluse dans les sources et dans les ressources de l’application.

Le CSS original définit une piste de 5 × 1 em, gris #ccc à gauche, bleu #2196F3 à droite. Le levier blanc fait 1,4 × 3,4 em, décalé de 0,3 em à gauche, avec une ombre noire de 5 px. Le passage à droite ajoute une translation de 2,5 em. L’original ajoute une rotation de −180° et une courbe avec dépassement pendant une seconde.

L’adaptation native conserve la piste et le levier vertical et effectue un glissement horizontal court, sans rotation. La réduction des animations macOS est respectée. Le contrôle est entièrement dessiné par SwiftUI, sans HTML, CSS embarqué ni WebView.
